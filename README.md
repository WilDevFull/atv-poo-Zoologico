# atv-poo-Zoologico
Objetivo: Criar um gerenciador para diferentes tipos de animais.  Técnica: Aplicar conceitos de Programação Orientada a Objetos (herança e polimorfismo), utilizando uma classe base Animal para manipular as subclasses.  Funcionalidades: O sistema deve ser capaz de adicionar, listar e remover os animais, além de executar seus sons e habilidades.
